# Security / Безопасность

Beta. This project adds a presentation-only JS payload to `dist/preload.js`, a sensitive Electron component. It does not modify the Antigravity executable, disable integrity enforcement, read credentials, install services, use MCP, communicate over the network, or automatically update. It changes the ASAR header and the target member's internal integrity records to reflect actual bytes, not to disable verification. Only packed archive members can be verified by this tool; unpacked files are not verified beyond preservation of their metadata. Do not use it to bypass an application integrity failure. Restore the original using the GUI if startup fails.

Known release 2.35.1 is pinned to the original supplied installer resources. For other releases, exact hashes of the known main and preload are required, as well as valid package metadata, archive integrity and Windows x64 PE format. That does not validate the publisher signature, all external dependencies, or runtime behavior; only use the official installer. Compatibility can still fail. The DOM-based scope uses known labels/selectors, not a formal security boundary: it is tested on fixtures, not exhaustively against real UI. The search helper only populates the existing field upon selection, never dispatches Enter or invokes a command. User text and unrelated alerts are excluded in tested fixtures; safety cannot be guaranteed for new DOM structures. Translated security descriptions must preserve their original meaning. No settings or permissions are changed.

Use the supplied original backup and state files; the patcher checks hashes and refuses unknown/tampered backups. Never restore a backup from a different version. Avoid concurrent app updates, keep a separate backup if the installation is important, and do not force elevation or disable Defender/SmartScreen. The unsigned EXE may trigger warnings; inspect source/build independently before trusting it. Report reproducible issues without credentials, personal data, logs, or tokens. Do not publish this as stable until native Windows testing and independent review are complete.

Version 0.6.1: the installer requests WM_CLOSE for visible windows whose process image path matches the selected Antigravity installation. No forced termination or privilege escalation. If any Antigravity.exe process remains after the bounded wait, file changes are blocked. Win32 process and window behavior has not been exercised on native Windows. Save ongoing work before starting the patcher.
